개인정보처리방침

시행일: 2026-11-21

1. shorts-upload (YouTube 업로드 도구)

이 도구는 운영자 본인의 Google 계정으로만 사용됩니다. Google 사용자 데이터 중 YouTube 업로드에 필요한 권한(https://www.googleapis.com/auth/youtube)만 사용하며, 운영자 본인 채널에 영상을 올리고 업로드 결과를 확인하는 용도로만 씁니다. 받은 인증 정보는 운영자 컴퓨터에만 저장하고, 제3자에게 제공·판매·공유하지 않습니다. Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 받은 데이터는 광고에 쓰지 않고, 사람이 열람하지 않으며, 업로드 기능 제공 외의 목적으로 이전하지 않습니다. 권한은 언제든 Google 계정 권한 페이지에서 해제할 수 있습니다.

2. 게임 앱

게임은 플레이 진행 데이터(진행도, 보유 아이템 등)와 로그인 방식에 따른 계정 식별자(게스트 ID, Google 또는 Apple 로그인 ID)를 게임 진행과 저장을 위해서만 처리합니다. 광고 추적을 하지 않으며, 수집 항목은 출시 전 각 스토어의 데이터 보안 안내에 정확히 공개합니다.

3. 보관과 삭제

계정 삭제를 요청하면 해당 계정과 게임 데이터를 30일 이내에 삭제합니다. 방법은 계정 삭제 안내를 참고하세요.
